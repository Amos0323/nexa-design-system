## Evidence boundary

The Phase 3 baseline recorded 75 unit tests and 10 browser tests. Phase 4 separates access-policy validation from the save-flow test while retaining their behavioral assertions; see the main README for current validation results. Tests establish specific behavior, not pixel equality with Figma. There is no completed Figma comparison, approved design version, screen-reader acceptance, or designer sign-off. Unit tests use JSDOM; browser checks use actual layout. Retain these distinctions when presenting the case study.

## Keeping links useful

When a component/story is renamed, update its source link, Storybook ID, and mapped test reference in the same change. After the Figma library is created, add a separate column containing actual node links and the reviewed version. Record new requirements and evidence without rewriting historical test results as if they proved the new design.
